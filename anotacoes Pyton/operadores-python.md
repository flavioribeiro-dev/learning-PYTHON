### Operadores Python:
- Soma ( + ).
- Subtração ( - ).
- Multiplicação ( * ).
- Divisão ( / ).
- Divisão: parte inteira ( // ).
- Módulo - Resto da Divisão ( % ).
- Potenciação ( ** ).

### Ordem de Precedência das Operações:
- Utilização dos Parênteses.
- Potenciação / Radiciação.
- Multiplicação / Divisão.
- Soma / Subtração.
